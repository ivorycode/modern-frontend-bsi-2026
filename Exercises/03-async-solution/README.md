# Musterlösung zu Übung 3: Wörter laden

Aufgabe: [Übung 3](../03-async/README.md)

```sh
npm install
npm run api    # Terminal 1: API auf http://localhost:3103/
npm run dev    # Terminal 2
```

Seiten: `http://localhost:5275/` (Satz laden) und `http://localhost:5275/suche.html` (Suche, Vertiefungen 1 und 2)

Prüfungen: `npm run check`, `npm test` und `npm run e2e`. `npm run e2e` startet API und Entwicklungsserver selbst.
