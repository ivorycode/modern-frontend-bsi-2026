# Prämienrechner: Fachliche Regeln

Die Tarifregeln sind **fiktiv**.

| Regel                       | Inhalt                                                                                                                                                                                                                                      |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R1 Altersgruppe             | Kind: 0 bis 18 Jahre. Junge Erwachsene: 19 bis 25 Jahre. Erwachsene: ab 26 Jahren. Erlaubt sind ganze Zahlen von 0 bis 120.                                                                                                                 |
| R2 Grundprämie pro Monat    | Kind CHF 104.65, junge Erwachsene CHF 329.80, Erwachsene CHF 437.35.                                                                                                                                                                        |
| R3 Franchise                | Kinder: CHF 0, 300 oder 600 mit einem monatlichen Rabatt von CHF 0, 15 bzw. 30. Junge Erwachsene und Erwachsene: CHF 300, 1000, 2000 oder 2500 mit einem monatlichen Rabatt von CHF 0, 40, 90 bzw. 115. Eine andere Franchise ist ungültig. |
| R4 Versicherungsmodell      | Standard: kein Rabatt. Hausarzt: 8 % Rabatt auf die Prämie nach Abzug des Franchiserabatts.                                                                                                                                                 |
| R5 Zahnversicherung         | Zuschlag von CHF 21.30 pro Monat.                                                                                                                                                                                                           |
| R6 Rundung                  | Die Monatsprämie wird auf 5 Rappen gerundet. Ab genau 2.5 Rappen wird aufgerundet. Jahresprämie = 12 × gerundete Monatsprämie.                                                                                                              |
| R7 Wechsel der Altersgruppe | Ist die gewählte Franchise für das neue Alter nicht erlaubt, wird automatisch die tiefste erlaubte Franchise gewählt.                                                                                                                       |

Beispiel: 40 Jahre, Franchise 2500, Hausarzt, mit Zahnversicherung: (437.35 − 115) × 0.92 + 21.30 = 317.862, gerundet **CHF 317.85** pro Monat und **CHF 3814.20** pro Jahr.
