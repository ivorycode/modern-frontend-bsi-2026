# Musterlösung zu Übung 7: Kursanmeldung mit Tailwind

Aufgabe: [Übung 7](../07-styling/README.md)

```sh
npm install
npm run dev
```

Seiten: `http://localhost:5278/` (Tailwind) und `http://localhost:5278/css-referenz/` (CSS-Referenz)

Prüfungen: `npm run check`, `npm test` und `npm run e2e`.

Gewählte Varianten und Beobachtungen stehen in [NOTIZEN.md](./NOTIZEN.md). Vertiefung 1 (dunkles Farbschema) wird mit der auskommentierten Importzeile in `src/main.ts` bzw. `css-referenz/main.ts` aktiviert, Vertiefung 2 ist auskommentiert in `src/tailwind.css`.
